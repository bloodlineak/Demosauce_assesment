# SauceDemo QA assessment

This project contains a small risk-based exploratory record and one Playwright/TypeScript end-to-end purchase test for the public SauceDemo demo site.

## Requirements

- Node.js 20 or later and npm
- Playwright's Chromium browser (install once with the command below)
- Network access to `https://www.saucedemo.com/`

## Setup and run

```sh
npm install
npx playwright install chromium
npm test
```

Useful scripts:

```sh
npm run test:headed  # run Chromium with a visible window
npm run test:ui      # open Playwright's test UI
npm run report       # open the latest HTML report
```

The test uses the public demo account `standard_user` / `secret_sauce`, creates a fresh browser context, and checks the Backpack name and price in the cart, the checkout subtotal/tax/total, and the completion message. It does not persist account data or change application configuration. One retry is enabled for transient failures; Playwright marks a test that passes only on retry as flaky in its report.

## Layout

- `tests/pages/locators.ts` — selectors, separate from action methods
- `tests/pages/actions.ts` — page actions
- `tests/checkout.spec.ts` — isolated end-to-end test
- `playwright.config.ts` — Chromium project and failure artifacts
- `SUBMISSION.md` — exploratory notes, confirmed findings, strategy, prompt log, and completion status

Reports, traces, videos, and screenshots generated by Playwright are local and ignored by Git. See `SUBMISSION.md` for the recorded validation results and limitations.
